# Описание
Мессенджер с возможностью анализировать содержимое отправляемых вложений, получать сводку по ним, искать конкретный файл по содержимому файлов в чате.
Также включает в себя базовые возможности мессенджера, отправка/чтение сообщений, отправка вложений, профили пользователей, уведомления.

## Запуск 
1. Backend
   У вас должен быть установлен docker compose.
   Для запуска баз данных и Apache Kafka необходимо ввести команду ```docker compose up -d``` в корне проекта.
   На данный момент запуск сервисов поддерживается только из IDE или самостоятельной сборкой сервисов и их запуском.
   Многие сервисы требуют ввод переменных окружения, таких как ключи шифрования, токены и другие данные.
2. Frontend
   Для запуска необходим node.js, т.к. приложение использует react.
   В каталоге ```messanger-ui``` введите команду ```npm run dev```.
   Приложение будет доступно по адресу ```http://localhost:5173```

Приложение активно развивается.
Следите за обновлениями!
