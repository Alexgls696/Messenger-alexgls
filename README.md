# Описание
Мессенджер с возможность анализировать содержимое отправляемых вложений, получать сводку по ним, искать файл по его содержимому файлов в чате.

## Запуск 
У вас должен быть установлен docker compose.
Для запуска баз данных и Apache Kafka необходимо ввести команду ```docker compose up -d``` в корне проекта.
На данный момент запуск сервисов поддерживается только из IDE.
Многие сервисы требуют ввод переменных окружения, таких как ключи шифрования, токены и другое.
Следите за обновлениями...
